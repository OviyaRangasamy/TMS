# AI Analysis Model Design

## Purpose
Stores output generated by the OpenAI integration for ticket enrichment and decision support.

## Core Fields
- id: string
- ticketId: string
- modelName: string
- analysisType: enum
- summary: string | null
- recommendedPriority: enum | null
- recommendedCategory: string | null
- confidenceScore: number | null
- createdAt: datetime
- providerResponse: object | null

## Analysis Types
- summary
- priority-recommendation
- categorization
- combined

## Schema Intent
This model captures AI-generated suggestions while preserving raw provider output for traceability, debugging, and future model improvements.

## Design Notes
- AI outputs should be stored separately from core ticket data
- Confidence and source details should be available for review
- Fallback handling should be designed for AI failure or latency scenarios
